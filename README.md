# Live-Currency-Strength-HeatMap

A Python-based dashboard that analyzes and visualizes relative strength across major currencies using real-time foreign exchange data.

The dashboard calculates pairwise strength relationships and displays a heatmap identifying strong and weak currencies in the market.
Real-time forex currency strength heatmap built with Python, powered by TradingView's live data via tradingview_ta
Fetches live forex rates for 28 major currency pairs directly from TradingView and calculates a relative strength index for the 8 major currencies (USD, EUR, GBP, JPY, CHF, CAD, AUD, NZD). Results are visualised as a colour-coded 8×8 heatmap — green for strong, red for weak — with optional auto-refresh every 60 seconds. No API key required.
